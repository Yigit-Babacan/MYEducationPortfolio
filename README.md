# Proje Hakkında

.NET ve Code First mimarisiyle geliştirilmiş; yetenekler, eğitim, deneyimler, projeler ve hakkımda gibi tüm bölümlerin tamamen dinamik bir admin paneli üzerinden yönetilebildiği kişisel portfolyo web projesi.

Bu proje, **M&Y Yazılım Eğitim Akademi (Murat Yücedağ)** kapsamında **1. Proje (Portfolyo Case)** olarak geliştirilmiştir.

### 🌐 Site (Vitrin / Kullanıcı Arayüzü)
- **Ana Sayfa (Öne Çıkan):** İsim, dinamik değişen çoklu unvanlar, tanıtım yazısı, deneyim yılı ve profil görseli.
- **Hakkımda:** Kişisel biyografi yazısı, fotoğraf ve dinamik istatistik sayaçları
- **Yeteneklerim:** Kategorilere ayrılmış teknik beceriler ve yüzdelik seviyeleri.
- **Deneyimlerim:** Mesleki deneyimlerin listelenmesi.
- **Projelerim:** Geliştirilen projelerin kategorilerine göre görselleri ve detaylarıyla sergilenmesi.
- **Eğitim:** Akademik geçmiş gösterilmesi.
- **İletişim & Sosyal Medya:** İletişim bilgileri, ziyaretçiler için mesaj gönderme formu ve GitHub, LinkedIn gibi sosyal medya bağlantıları.

### 🛠 Admin Paneli
- **Dashboard:** Genel sistem özeti ve istatistik ekranı.
- **Ana Sayfa & Ünvan Yönetimi:** Giriş bilgilerini düzenleme ve birden fazla unvan ekleyip aktif/pasif durumlarını yönetme.
- **Hakkımda Yönetimi:** Biyografi metni, başlık ve görsel güncelleme.
- **Yetenek Yönetimi:** Kategori bazlı yetenek ekleme, silme ve oran güncelleme.
- **Deneyim & Eğitim Yönetimi:** İş/staj ve okul bilgilerini dinamik olarak düzenleme.
- **Proje & Kategori Yönetimi:** Projeleri ve bağlı oldukları kategorileri yönetme.
- **İletişim & Sosyal Medya Yönetimi:** İletişim bilgilerini ve sosyal medya ikon/linklerini güncelleme.
- **Gelen Mesajlar:** Ziyaretçilerden gelen mesajları görüntüleme, silme, okundu/okunmadı takibi ve menü üzerinde dinamik bildirim sayacı.

## 🚀 Kullanılan Teknolojiler

- ASP.NET Core MVC
- C#
- Entity Framework Core (Code First & Migrations)
- MS SQL Server
- LINQ
- HTML5, CSS3, JavaScript
- Razor Views & ViewComponents
